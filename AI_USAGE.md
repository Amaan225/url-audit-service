# AI Usage Statement

This project was developed with the assistance of AI tools (ChatGPT) as a software development aid throughout the implementation process.

AI was used for:

- Explaining backend engineering concepts such as FastAPI, asynchronous programming, Redis, Docker, middleware, logging, and deployment.
- Providing guidance on debugging runtime errors, deployment issues, GitHub Actions failures, Docker configuration, and Redis connectivity.
- Suggesting implementation approaches, best practices, project organization, testing strategies, and documentation structure.
- Reviewing code and helping identify potential improvements in performance, maintainability, and readability.

The project itself was implemented, integrated, tested, debugged, deployed, and validated by me. All final architectural decisions, code modifications, debugging, testing, deployment, documentation, and verification were performed manually to ensure the application met the assignment requirements.

AI served as a development assistant to accelerate learning, explain concepts, and improve productivity. Every generated suggestion was reviewed, adapted where necessary, and verified before being incorporated into the final project.
